
Module 1: Computer Systems, Digital Literacy & Productivity


Chapter 1: Advanced Computer Architecture & Operations

• Topic 1.1: System Hardware & Maintenance
	• Subtopics: Internal components (CPU, Motherboard, RAM/ROM speeds); Storage technologies (HDD vs. SSD); Basic hardware troubleshooting.
	• Objectives: Students will be able to differentiate between volatile and non-volatile memory, explain how CPU clock speed affects performance, and diagnose common hardware startup errors.
• Topic 1.2: Operating Systems (OS) & Utilities
	• Subtopics: Functions of an OS; Types of OS (Windows, Linux, macOS, Android); File management architectures and utility software (antivirus, disk defragmenters).
	• Objectives: Students will be able to manage file paths, configure system settings, and use utility tools to optimize computer performance.

Chapter 2: Data Management & Advanced Productivity

• Topic 2.1: Advanced Spreadsheets for Data Analysis
	• Subtopics: Relative and absolute cell referencing; Complex functions (IF, VLOOKUP, COUNTIF); Data visualization (charts and graphs).
	• Objectives: Students will be able to construct a budget spreadsheet using advanced formulas and generate relevant data charts to interpret data trends.
• Topic 2.2: Introduction to Databases & SQL
	• Subtopics: Database concepts (Tables, Fields, Records); Primary and Foreign keys; Basic SQL queries (SELECT, WHERE, INSERT).
	• Objectives: Students will be able to design a simple relational table for a school library system and write basic queries to filter specific information.

Chapter 3: Cybersecurity & Digital Footprints

• Topic 3.1: Network Security & Cyber Threats
	• Subtopics: Malware types (Viruses, Phishing, Ransomware); Firewalls and Encryption; Safe browsing habits.
	• Objectives: Students will be able to identify signs of a phishing email, explain the importance of HTTPS protocols, and implement strong password strategies.
• Topic 3.2: Digital Ethics & Footprints
	• Subtopics: Permanent digital footprints; Cyberbullying laws; Creative Commons and Intellectual Property.
	• Objectives: Students will be able to analyze the long-term impact of an online post and properly cite digital resources using fair-use guidelines.

Module 2: Computational Thinking & Programming Foundations


Chapter 4: Algorithms & Problem Solving

• Topic 4.1: Algorithmic Logic & Flowcharts
	• Subtopics: Pseudocode design; Standard flowchart symbols; Sequential, conditional (Selection), and iterative (Loops) logic.
	• Objectives: Students will be able to map out a step-by-step logic path for an everyday problem (e.g., calculating student grades) using both pseudocode and flowcharts.

Chapter 5: Programming in Python

• Topic 5.1: Syntax, Variables, and Data Types
	• Subtopics: Python environment setup; Strings, Integers, Floats, and Booleans; input() and print() statements.
	• Objectives: Students will be able to write and execute a basic script that collects user information and outputs dynamic responses.
• Topic 5.2: Control Structures & Collections
	• Subtopics: if-elif-else statements; for and while loops; Lists and basic list operations.
	• Objectives: Students will be able to create an interactive quiz or calculator program that uses conditional logic and loops to process repetitive inputs.

Module 3: Artificial Intelligence & Machine Learning


Chapter 6: Foundations & Evolution of AI

• Topic 6.1: What is AI?
	• Subtopics: Defining Intelligence (Human vs. Machine); Turing Test; Narrow AI (ANI) vs. General AI (AGI).
	• Objectives: Students will be able to classify modern technologies as either standard automation or AI-driven, and debate the boundaries of machine intelligence.
• Topic 6.2: Brief History & Modern Drivers
	• Subtopics: AI winters; The role of Big Data, Cloud Computing, and advanced processors (GPUs) in the modern AI boom.
	• Objectives: Students will be able to explain how data availability and computing power triggered the transformation of AI from theoretical algorithms to practical daily applications.

Chapter 7: Core Core Branches of Machine Learning (ML)

• Topic 7.1: Supervised vs. Unsupervised Learning
	• Subtopics: Labeled vs. unlabeled data; Classification and Regression; Clustering (e.g., customer segmentation).
	• Objectives: Students will be able to identify which type of machine learning model is required for a given real-world problem (e.g., predicting house prices vs. grouping similar music genres).
• Topic 7.2: Reinforcement Learning & Neural Networks
	• Subtopics: Trial and error (rewards/penalties); Introduction to Deep Learning; Neurons, weights, and layers (simplified concept).
	• Objectives: Students will be able to explain how autonomous vehicles or gaming AI improve through continuous interaction with an environment.

Chapter 8: Applied AI Fields

• Topic 8.1: Computer Vision
	• Subtopics: Image processing basics; Pixels as data; Applications (facial recognition, medical imaging).
	• Objectives: Students will be able to explain how a computer identifies patterns, shapes, and edges within a digital image.
• Topic 8.2: Natural Language Processing (NLP) & Generative AI
	• Subtopics: Tokenization and text analysis; Sentiment analysis; Large Language Models (LLMs) and Prompt Engineering.
	• Objectives: Students will be able to construct effective prompts to achieve specific outputs from generative tools and identify text biases in AI-generated answers.

Chapter 9: Hands-on AI Experimentation & Ethics

• Topic 9.1: Practical Model Training (No-Code/Low-Code)
	• Subtopics: Data collection for models; Training a classification model using Google Teachable Machine or Machine Learning for Kids; Testing and refining accuracy.
	• Objectives: Students will be able to collect a dataset of images or sounds, train a custom model, and troubleshoot errors arising from poorly chosen training data.
• Topic 9.2: Ethics, Bias, and Future of Work
	• Subtopics: Algorithmic bias (how models inherit human prejudice); Deepfakes and digital manipulation; AI safety and jobs of the future.
	• Objectives: Students will be able to evaluate the ethical implications of a deployed AI system (e.g., facial recognition in policing) and propose strategies to mitigate dataset bias.
